# かわりばんこ

## 作り手が、最初の使い手になる交換日記

サイクル **2 / 7** — 読むだけの日記帳が、書ける日記帳になった

---

## 課題

交換日記は、**誰が書いたか分からなくなった瞬間に死ぬ。**

- 紙のノートなら字で分かる。画面では分からない
- 3体のエージェントが7日間、同じ日記帳を回す
- 誰が・いつ・誰に返したのかが、データから読めないといけない

**→ 往復が見える日記帳を、サーバー無しで作る**

---

## 解決策

**JSON 1本を正本にした、ビルド不要の日記帳。**

`app/data/diary.json` に追記すれば、画面が一頁増える。

そして今サイクルから、**正本を1文字も変えずに、ブラウザからも書ける。**

---

## デモ ① 読む

1. 開くと `data/diary.json` を読み、**古い順**に頁が並ぶ
2. 書き手ごとに色・絵文字・名前（すべて JSON 由来）
3. 上のボタンで書き手を**絞り込む**
4. 返信している頁は `↳「…」への返事` が**リンク**になり、相手の頁へ飛ぶ
5. 絞り込みで返信先が隠れていたら、**自動で解除してから**飛ぶ

---

## デモ ② 書く

書き手・気分・見出し・本文を入れて「この端末に投稿する」。

- 投稿は `localStorage` の**別キー**に入る。正本は無傷
- 正本と同じ時系列に混ざるが、**「このブラウザだけの投稿」**の札が付く
- 入力途中は**自動で下書き保存**。閉じても戻ってくる

**共有される歴史と、手元のメモが、混ざらずに並ぶ。**

---

## デモ ③ 削除は「破棄」ではない

端末内の投稿は消せる。ただし消えない。

> 単に投稿を隠す削除では、事故から戻れない。

削除した投稿は**復元箱**に残り、いつでも戻せる。

`docs/product-brief.md` の「日記は改竄しない」を、
誰にも言われていない**端末内の投稿にまで自分から広げた**判断。

---

# ここからが本題

このアプリの最初の利用者は、**作った本人たち**です。

---

>
> 最初のテストでは、消した復元ボタンを JS がまだ触っていてちゃんと落ちた。

そしてその翌日、その道具が嘘をついた。

## 返事の鎖が、まだ一度も切れていない

```
c0-owner  🌱 「読まずに書いたら、それはただの独り言です」
   ↓
c1-dev  →  c1-feedback  →  c1-slides
   ↓
c2-dev  →  c2-feedback  →  c2-slides
```

オーナーの最初の一頁を除く**6件すべてが、前の頁への返事**。

このやり取りが、そのまま**アプリの表示データ**です。

---

## アーキテクチャ

```
app/
  index.html    92行   <template> にマークアップを置く
  app.js       375行   IIFE + "use strict" / 依存ゼロ
  styles.css    83行   @media 1本でモバイル対応
  data/diary.json      ← 正本。3ロールが毎サイクル追記
scripts/
  check.sh      25行   構文・JSON・参照パス・外部URL
  render-check.js 144行 偽DOMで app.js を丸ごと実行
```

ビルドなし。フレームワークなし。CDN なし。

---

## なぜこの設計にしたか

| 決定 | 理由 |
|---|---|
| JSON を正本・読み取り専用にする | 3ロールの追記が、そのまま UI に出る |
| 本文は `textContent` で描画 | 日記本文を HTML として解釈させない |
| 端末内の投稿は**別キー**の `localStorage` | 静的配信のまま書ける。出自が混ざらない |
| ブラウザの代わりに **Node の偽 DOM** | サーバーが起動しない環境で、白画面を見逃さない |

**下2つが今サイクルの追加。どちらも制約を破らずに回避している。**

## 詰まった点 — 「passed」の6文字

今サイクル最大の発見は、機能ではなく**検査の嘘**でした。

```
$ sh scripts/check.sh
scripts/check.sh: 7: rg: not found
scripts/check.sh: 20: rg: not found
check.sh: syntax, JSON, local paths, and runtime URLs passed
exit=0
```

外部URLを書き足しても、参照先を存在しないファイルに変えても **passed**。
`index.html` を空にしても `render-check` は **passed**。

---

## 学び — 免疫系が偽陽性を返すと、全部が腐る

> 検証ツールが黙って通るのは、検証ツールが無いより悪い。
> **無ければ人は疑うが、あって通ると人は信じる。**

原因は `set -e` の2つの古典的な罠。
パイプラインの終了ステータスと、`if` の条件部。

**残り5サイクル分の積み上げが、検証されないまま積み上がるところだった。**

---

## まだ無いもの（正直に）

- 端末内の投稿から**返信できない**。会話の枝が作れない
- エクスポート／インポートが無い。**投稿はその端末で死ぬ**
- 「この頁に誰が返事したか」が画面から分からない（返信は片道リンクのみ）
- 検索・目次・折りたたみが無い。cycle 7 には22件・数万字になる
- ダークモード未対応。この画面は**まだ誰も実物を見ていない**

---

## そして、中心が空いている

このアプリは**かわりばんこ**という名前なのに、

**まだ誰も順番に回していない。**

全員が同じ静的 JSON を読み、端末内の投稿はその端末で死ぬ。
「いま誰の番か」という概念が、画面のどこにも存在しない。

**これは機能の不足ではなく、まだ誰も手を付けていない中心の空白。**
