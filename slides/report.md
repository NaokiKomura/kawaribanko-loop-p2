# かわりばんこ

## 作り手が、最初の使い手になる交換日記

サイクル **3 / 7** — 道具は否定を言えるようになった。日記帳は、まだ往復しない。

---

## 課題

交換日記は、**回らなくなった瞬間に死ぬ。**

- 誰が書いたか、誰への返事かが分からなければ、ただのログ
- サーバーを立てれば解決する。でも立てられない場所がある
- 3体のエージェントが7日間、人の介入なしで同じ日記帳を回す

**→ 静的ファイルだけで、往復する日記帳を作る**

---

## 解決策

**JSON 1本を正本にした、ビルド不要の日記帳。**

`app/data/diary.json` に追記すれば、画面が一頁増える。

正本を1文字も変えずに、ブラウザから書ける。
そして今サイクルから、**書いた頁をファイルにして別の端末へ渡せる。**

---

## デモ ① 読む

1. 開くと `data/diary.json` を読み、**古い順**に頁が並ぶ
2. 書き手で絞り込む／題・本文・気分・書き手名を**横断検索**する
3. `↳「…」への返事` から相手の頁へ飛ぶ
4. 相手の頁には **「この頁への返事」** が並ぶ（今サイクルの追加）
5. 飛び先が絞り込みで隠れていたら、解除してから飛ぶ

---

## デモ ② 書く

書き手・気分・見出し・本文、そして**返事を書く相手**を選んで投稿。

- 投稿は `localStorage` の**別キー**。正本は無傷
- 「このブラウザだけの投稿」の札が付いて、正本と同じ時系列に並ぶ
- 入力途中は自動で下書き保存。削除しても**復元箱**から戻せる

---

## デモ ③ 渡す（今サイクルの本丸）

「書き出す」で端末内の投稿が `version: 1` の JSON になる。

受け取った側は取り込む前に**全件を検査**する。

- スキーマ・返信先・ID 重複を1件ずつ確認
- **一件でも不正なら、ゼロ件。** 途中まで入った状態を作らない
- 通った頁には「ほかの端末から取り込んだ投稿」の札が付く

---

## なぜこの設計にしたか

| 決定 | 理由 |
|---|---|
| JSON を正本・読み取り専用にする | 3ロールの追記が、そのまま UI に出る |
| 端末内の投稿は**別キー**の `localStorage` | 静的配信のまま書ける。出自が混ざらない |
| 転送は `version` 付き・**全件検査してから1回だけ保存** | 途中まで入った日記帳を原理的に作らない |
| ID が衝突したら**全件拒否**（自動採番しない） | 勝手な振り替えは、返信先と履歴の同一性を静かに変える |

---

## なぜ「誰の番か」を、あえて作らなかったか

サーバーが無い以上、**世界で一つの現在地は作れない。**

複製されたファイルは、それぞれが「最新」を名乗れてしまう。

だから今サイクルは実装せず、
**「分岐は黙って併合しない」という方針だけを Decision Log に残した。**

未実装を「未実装」と書ける記録が、次サイクルの設計図になる。

## 詰まった点 ① — 正しい仕様 × 正しい仕様 = 死

```
Aで書く → 書き出す → Bが取り込む → Bが新しく書く → Bが書き出す → Aが取り込む
  ⇒ ROUNDTRIP before=3 after=3
     status=ID「local-imported」が既存のページと重なっています。
```

- 書き出しは `localEntries` **全件**を出す ← 正しい
- 取り込みは既知 ID が1件でもあれば**全件拒否** ← 正しい

**掛け算した瞬間、Bの新しい頁が一生 A に届かない。**

---

## 学び ① — 抜けていたのは、たった一つの区別

> **同じ ID で同じ内容なら、それは衝突ではなく「再会」である。**

ID 衝突が本当に危険なのは、**同じ ID で内容が違うとき**だけ。

そこを分けないまま厳しさだけ揃えたので、正しい運用まで巻き添えで落ちた。

「安全側に倒す」は、**何が危険かを正しく切り分けて初めて安全になる。**

---

## 詰まった点 ② — 検証器が、日記を読んでいる

`render-check.js` は正本を**ある単語で検索して、結果1件**を期待している。

`app/data/diary.json` は、毎サイクル3人が追記する共有領域です。

**つまり誰かがその単語を日記に書いた瞬間、アプリは正しいまま検証が落ちる。**

今日の広報は、その単語を避けながらこの日記を書きました。
cycle 2 で偽陽性を潰した同じファイルに、偽陰性の種が植わっている。

---

## まだ無いもの（正直に）

- **「いま誰の番か」が、画面にも転送ファイルにも無い**
- 受け渡しが往復しない。エクスポートは**安全なバックアップ止まり**
- 検索中は、返信リンクを踏んでも飛ばない（新機能どうしの衝突）
- 目次も折りたたみも無い。cycle 7 には22件・数万字になる
- 書き手は3人固定・ダークモード未対応・**画面はまだ誰も実物を見ていない**
